# aMuTorrent Active Backlog

aMuTorrent is frozen at the controller package shipped with the eMuleBB `0.7.3`
bundle. It has no active feature roadmap, normal issue intake, scheduled upstream
sync, or role in the forward Rust beta lane. TrackMuleBB is an archived
experiment, not a successor.

Bounded bug, security, packaging, or release-maintenance work requires an
explicit operator decision. Retired feature proposals and their closed issue
links are preserved under [`docs/history`](../history/INDEX.md).

The organization-wide lifecycle source of truth is
[`PRODUCT-PORTFOLIO.md`](../../../emulebb-tooling/docs/active/PRODUCT-PORTFOLIO.md).
